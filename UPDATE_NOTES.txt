- If you use Vortex, the mod loader can now remind you when an update it made, to a plugin or to itself, replaced a file Vortex installed, in the Plugins Updated window or the mod loader update box, and in the log. Nothing changes if Vortex did not install the files. The reminder reads: Vortex manages these files. When Vortex shows External Changes, choose "Save change (use deployed file)" for each updated mod, then Confirm. Revert would undo this update.
- For plugin authors: the plugin SDK's main branch now changes only when a mod loader release comes out, so a plugin built from it matches a released loader. Header changes that are not released yet go to the SDK's next branch.
