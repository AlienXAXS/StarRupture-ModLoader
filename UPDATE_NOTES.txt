- New `DL_AddTexturedTriangles` plugin call for drawing many textured triangles in one call (plugin interface v78), so a plugin with a large set of icons, a GPU-drawn map for example, needs one draw call instead of one per icon. Plugins that use it need ModLoader 1.25.0 or newer. Added by Kian369
- A mod that has to wait for the game's graphics while it shuts down can now be unloaded or reloaded. The loader no longer holds the plugin lock while the mod shuts down, so the mod windows and the plugin list keep drawing, and the mod's row in the plugin list says "This plugin is being unloaded right now" in place of its buttons. Unloading or reloading the same mod again during that time is refused
- When the game closes, the loader waits up to 5 seconds for an unload that is still in progress, and then goes on without that mod
- The save and persistent ID functions the PersistentIdFix mod looks up (GetSaveData, OnPreLoadMap, SetIDHandlePair and GetOrAddIDForHandle) are now rows of the version object map for both game builds, so the mod finds all of them on either one
- The version map has the rows MiniMap reads on the current game build (building ID, entity type, building tags, the ramp walkway spline mesh and the game state size), and the spline payload type's address on the upcoming game build
- Needs ModLoader 1.25.0 or newer for mods that use bulk textured triangles (plugin interface v78)
