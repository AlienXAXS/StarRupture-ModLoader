- The loader now checks for a newer version object map at every start even when Auto Updates is off. Before, a player with Auto Updates off did not get newer ones and stayed on the version map built into the loader, so a new game build ran without mods or on checked values. Turning Auto Updates off still stops loader update prompts and plugin updates. A new `Fetch` setting under `[VersionMap]` in `modloader.ini` (1 by default) turns the version map check off
